# Integrate code generator for REST API objects

Look at https://raw.githubusercontent.com/gzuidhof/tygo/refs/heads/main/README.md
We currently have rest objects defined in Golang, folder `backend/server/rest_objects`
Additionally we have same objects defined in TypeScript, folder `frontend/src/typescript/personal-goals`
The goal is to generate TypeScript files from Golang files. Use the aforementioned `tygo` generator.
Does not have to be perfect. The important thing is to get started and do the initial setup.
We polish it afterwards if need arises.
